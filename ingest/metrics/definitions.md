# KPI Definitions (v0)
- Null rate = null cells / (rows × required_fields)
- Duplicate row rate = (duplicates by full row signature) / rows
- Valid category % = rows with category ∈ {Hosting,Software,Travel,Ads} / rows
- Positive amount % = rows with amount > 0 / rows
- Valid currency % = rows with currency ∈ {USD,INR} / rows
- Monthly spend = Σ amount grouped by month
